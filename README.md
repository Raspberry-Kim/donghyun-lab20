# 동현페 v0.31

술탄의 딸 **아몰랑**이 갑자기 심심해져서 모험을 나선다. **시작 층·남은 시간·체력 칸·벽돌색·음악**은 동현랭 코드로 정하고, 달리고 뛰고 매달리는 것은 키보드로 한다. 층은 열넷이다.
동현 시리즈의 스물한 번째 작은 실험이다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab20/

## 먼저 알아 둘 것

동현페는 1999년에 나온 Prince of Persia 게임보이 컬러판의 프로그램을 자바스크립트로 옮겨 구동한다. 원작의 층 자료·배경 그림·소리 자료 228,169바이트와 옮긴 프로그램이 `pe/` 폴더에 들어 있다. 이 부분의 권리는 원작 권리자에게 있고, 나는 허락을 받지 않았다. 원작 권리자가 원하면 저장소와 페이지를 바로 내리고, Zenodo 보관본은 Zenodo에 지워 달라고 요청한다. 비영리이며 후원을 받지 않는다. 원작 롬 파일은 이 저장소에 없다.

## 동현페 규약

동현랭 코드가 출력한 **정수 다섯**이 차례로 출전 설정이다.

| 차례 | 뜻 | 범위 | 기본값 |
|---|---|---|---|
| 1 | 시작 층 | 1–14 | 1 |
| 2 | 남은 시간(분) | 1–60 | 60 |
| 3 | 체력 칸 | 1–9 | 3 |
| 4 | 벽돌색(0 노랑 · 1 본래 색) | 0·1 | 0 |
| 5 | 음악(0 끔 · 1 켬) | 0·1 | 0 |

- 출력이 없으면 기본값 `1 60 3 0 0`으로 나선다.
- 다섯 개가 아니거나 범위를 벗어나면 나서지 않고 오류를 알린다.
- 음악을 꺼도 효과음은 난다.
- 층을 넘을 때마다 층·남은 시간·체력 칸을 브라우저에 적어 두고, 다음에 **이어하기**로 그 층의 처음부터 잇는다.
- 13층과 14층에서도 화면의 층 알림은 원작 그대로 “LEVEL 12”다. 원작은 마지막 세 구역을 한 층으로 센다.

예제는 여섯이다: 기본(1층 · 60분), 느긋한 산책(체력 9칸), 궁전 구경(4층 · 본래 색), 음악과 함께(7층), 15분 돌파(12층 · 체력 1칸), 계산해서 정하기(남은 시간 = 64 − 층 × 4).

```
나는 동현이냐?
ㅋㅋ 시작 층 1
뿡뿡 도옹~뿡뿡뿡
ㅋㅋ 남은 시간(분) 60
뿡뿡 도오오오오오오오오오옹 도오오오오옹~뿡뿡뿡
ㅋㅋ 체력 칸 3
뿡뿡 도오옹~뿡뿡뿡
ㅋㅋ 벽돌색(0 노랑 · 1 본래 색) 0
뿡뿡 도옹ㅠ~뿡뿡뿡
ㅋㅋ 음악(0 끔 · 1 켬) 0
뿡뿡 도옹ㅠ~뿡뿡뿡
동현이구나
```

## 조작

| 키 | 하는 일 |
|---|---|
| ← → | 달리기 · 돌아서기 |
| ↑ | 뛰어오르기 · 위 칸 잡고 오르기 · 문으로 들어가기 |
| ↓ | 앉기 · 끝에서 매달려 내려가기 |
| X | 멀리 뛰기 · 칼싸움에서 찌르기 |
| Z | 살금살금 · 줍기 · 매달려 버티기 · 칼 |
| Enter | 쓰러진 뒤 그 층 다시 시작 |
| P · M | 잠깐 멈춤 · 소리 끄기와 켜기 |

**데스크톱에서 키보드로** 하기를 권한다. 달리기와 뛰기를 함께, 정확한 때에 눌러야 하는 게임이다.

게임패드는 닌텐도 배치다(십자키·왼 스틱 이동, A 멀리 뛰기, B 살금살금·줍기·칼, Start 다시 시작). 휴대폰·태블릿에는 화면 버튼이 붙는다.

## 폴더

- `src/` 페이지(HTML·CSS·JS), 동현랭 실행기, 예제, 시리즈 띠
- `pe/` 게임 화면과 엔진: `game.html`, `core.js`(옮긴 프로그램), `data.js`(원작 자료), `atlas.js`(아몰랑 그림 578장), `game.js`(그림 바꾸기·가림·저장), `apu.js`(소리), `gamepad.js`
- `engine/` 내가 짠 엔진 소스(`src/`), 아몰랑 그림(`assets/`), `pe/` 폴더를 묶는 `pack.py`. 원작 프로그램을 옮기고 자료를 뽑는 도구와 조사 기록은 이 저장소에 넣지 않았다. 그래서 `pe/core.js`의 옮긴 프로그램과 `pe/data.js`는 이 저장소만으로 다시 만들 수 없다.
- `qa/` 시험

## 만들기와 시험

```
node build.cjs            # src → index.html, dist/
node qa/core-tests.cjs    # 규약·예제 8묶음
node qa/engine-tests.cjs  # 엔진 6묶음(화면 없이)
```

## 한계

- 제목 화면·암호 입력·끝 장면은 없다. 곧바로 층에서 시작하고, 마지막 방에 들어서면 끝 카드가 나온다.
- 그림자와 거울 속 모습은 원작 주인공 그림 그대로다. 아몰랑으로 바꾸지 않았다.
- 원작 기기의 한 줄 스프라이트 10개 제한을 넣지 않았다. 원작에서 깜박이던 곳이 깜박이지 않는다.
- 자동 실행으로 1층부터 14층 끝까지 이어지는 것을 확인했다. 사람이 끝까지 해 본 것은 아니다. 실제 휴대폰·게임패드에서는 확인하지 않았다.
