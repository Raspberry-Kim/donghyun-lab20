# 동현페 v0.63

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24430550.svg)](https://doi.org/10.5281/zenodo.24430550)

술탄의 딸 **아몰랑**이 갑자기 심심해져서 모험을 나선다. **시작 층·남은 시간·체력 칸·색상·음악**은 동현랭 코드로 정하고, 달리고 뛰고 매달리는 것은 키보드로 한다. 층은 열넷이다.
동현 시리즈의 스물한 번째 작은 실험이다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab20/

모든 판을 묶는 DOI는 [`10.5281/zenodo.24430550`](https://doi.org/10.5281/zenodo.24430550)이다. 이번 판은 [v0.63 릴리스](https://github.com/Raspberry-Kim/donghyun-lab20/releases/tag/v0.63)이며 Zenodo 보관본은 [records/24461752](https://zenodo.org/records/24461752)(DOI `10.5281/zenodo.24461752`)이다. 보관본에는 `pe/core.js`와 `pe/data.js`가 들어 있지 않다.

## 먼저 알아 둘 것

동현페는 1999년에 나온 Prince of Persia 게임보이 컬러판의 프로그램을 자바스크립트로 옮겨 구동한다. 원작의 층 자료·배경 그림·소리 자료 228,169바이트와 옮긴 프로그램이 `pe/` 폴더에 들어 있다. 이 부분의 권리는 원작 권리자에게 있고, 나는 허락을 받지 않았다. 원작 권리자가 원하면 저장소와 페이지를 바로 내린다. 릴리스 묶음과 Zenodo 보관본에는 이 두 파일(`pe/core.js`, `pe/data.js`)을 넣지 않았다. 비영리이며 후원을 받지 않는다. 원작 롬 파일은 이 저장소에 없다.

## 동현페 규약

동현랭 코드가 출력한 **정수 다섯**이 차례로 출전 설정이다.

| 차례 | 뜻 | 범위 | 기본값 |
|---|---|---|---|
| 1 | 시작 층 | 1–14 | 1 |
| 2 | 남은 시간(분) | 1–60 | 60 |
| 3 | 체력 칸 | 1–9 | 3 |
| 4 | 색상(0 그레이스케일 · 1 컬러 · 2 본래 색 · 3 연필) | 0–3 | 0 |
| 5 | 음악(0 끔 · 1 켬) | 0·1 | 1 |

- 출력이 없으면 기본값 `1 60 3 0 1`로 나선다.
- 다섯 개가 아니거나 범위를 벗어나면 나서지 않고 오류를 알린다.
- 색상 0 그레이스케일은 CGA 네 색 화면을 흰 형광체 흑백 모니터로 보던 때의 색감이다. 검정·어두운 회색·밝은 회색·흰색 네 단계로 그린다. 아몰랑이 좌우로 가다 부딪히는 벽 옆면에는 어두운 회색보다 짙은 다섯째 회색을 쓰고, 아몰랑의 머리와 바지는 밝은 회색으로 그려 벽과 구분한다. 기본값이다.
- 색상 1 컬러는 파스텔이다. 벽돌은 버터빛 노랑, 바탕은 짙은 남보라로 두고 횃불·체력·문 같은 나머지 색은 채도를 낮춘다. 색상 2는 층마다 다른 원작의 본래 색이다.
- 색상 3 연필은 네 단계 회색 화면을 종이 위 연필 그림으로 옮긴다. 면은 종이로 남기고 손으로 그은 듯 흔들리는 선으로 윤곽을 겹쳐 긋는다. 어두운 면에는 빗금을 넣고, 넓은 어둠은 칠하지 않는다. 아몰랑과 경비병은 둘레를 종이로 비워 배경과 구분한다. 아래 띠의 체력·시간·층 글자는 짙게 칠한다. 화면은 세 배(960×864)로 그린다. 예제에는 없고, 넷째 값을 3으로 적으면 나온다.
- 음악은 층을 시작할 때와 장면이 바뀔 때 나오는 원작의 짧은 곡이다. 예제와 기본값은 모두 켬(1)이다. 0으로 꺼도 효과음은 난다.
- 층을 넘을 때마다 층·남은 시간·체력 칸을 브라우저에 적어 두고, 다음에 **이어하기**로 그 층의 처음부터 잇는다. 아래의 저장과는 따로다.
- 13층과 14층에서도 화면의 층 알림은 원작 그대로 “LEVEL 12”다. 원작은 마지막 세 구역을 한 층으로 센다.

예제는 열둘이다. 여섯 가지 출전을 그레이스케일 · 컬러의 둘씩 묶었다: 기본(1층 · 60분), 느긋한 산책(체력 9칸), 궁전 구경(4층), 일곱째 층에서(7층 · 체력 4칸), 15분 돌파(12층 · 체력 1칸), 계산해서 정하기(남은 시간 = 64 − 층 × 4). 번호는 출전마다 그레이스케일, 컬러 차례이고, 한 묶음 안에서는 넷째 값만 다르다. 아래는 01 · 기본 · 그레이스케일이다.

```
나는 동현이냐?
ㅋㅋ 기본 · 그레이스케일
ㅋㅋ 시작 층 1
뿡뿡 도옹~뿡뿡뿡
ㅋㅋ 남은 시간(분) 60
뿡뿡 도오오오오오오오오오옹 도오오오오옹~뿡뿡뿡
ㅋㅋ 체력 칸 3
뿡뿡 도오옹~뿡뿡뿡
ㅋㅋ 색상(0 그레이스케일 · 1 컬러 · 2 본래 색 · 3 연필) 0
뿡뿡 도옹ㅠ~뿡뿡뿡
ㅋㅋ 음악(0 끔 · 1 켬) 1
뿡뿡 도옹~뿡뿡뿡
동현이구나
```

## 조작

| 키 | 하는 일 |
|---|---|
| ← → | 달리기 · 돌아서기 |
| ↑ | 뛰어오르기 · 위 칸 잡고 오르기 · 문으로 들어가기 |
| ↓ | 앉기 · 끝에서 매달려 내려가기 |
| X | 멀리 뛰기 · 칼싸움에서 찌르기 |
| Z | 살금살금 · 줍기 · 매달려 버티기 · 칼 |
| Enter | 쓰러진 뒤 그 층 다시 시작 |
| P · M | 잠깐 멈춤 · 소리 끄기와 켜기 |

**데스크톱에서 키보드로** 하기를 권한다. 달리기와 뛰기를 함께, 정확한 때에 눌러야 하는 게임이다.

게임패드는 닌텐도 배치다(십자키·왼 스틱 이동, A 멀리 뛰기, B 살금살금·줍기·칼, Start 다시 시작). 휴대폰·태블릿에는 화면 버튼이 붙는다.

## 저장과 불러오기

게임 화면 아래의 **저장**을 누르면 게임이 멎고 메뉴가 뜬다. 브라우저 칸 셋 가운데 하나에 적거나 `.dhsave` 파일로 내려받는다. **불러오기**는 칸이나 파일에서 저장한 그 순간으로 돌아간다. 층·방·남은 시간·체력은 물론 색상과 음악도 저장할 때 그대로이고, 편집기의 코드는 바뀌지 않는다. 전체 화면에서도 같은 버튼이 화면 위쪽에 함께 뜬다. 저절로 저장하지는 않는다.

- 브라우저 칸(`localStorage`의 `donghyunpe.slot.1`–`3`)은 이 기기의 이 브라우저에만 남는다. 오래 두거나 옮기려면 파일로 내려받는다.
- 저장 파일(`donghyunpe-save-1`)에는 게임의 기억 장치 33,198바이트가 통째로 들어간다. 묶음 하나가 약 1.6만 글자다. 엔진이 바뀐 뒤의 판에서는 읽지 못할 수 있다.
- v0.33까지의 판에서 저장한 것은 넷째 값을 옮겨 읽는다. 노랑(0)은 컬러(1)로, 본래 색(1)은 본래 색(2)으로 연다.
- 불러온 직후에는 울리고 있던 음이 다시 울리지 않고, 다음 음부터 난다.

## 폴더

- `src/` 페이지(HTML·CSS·JS), 동현랭 실행기, 예제, 시리즈 띠
- `pe/` 게임 화면과 엔진: `game.html`, `core.js`(옮긴 프로그램), `data.js`(원작 자료), `atlas.js`(아몰랑 그림 578장), `game.js`(그림 바꾸기·가림·저장), `apu.js`(소리), `gamepad.js`
- `engine/` 내가 짠 엔진 소스(`src/`), 아몰랑 그림(`assets/`), `pe/` 폴더를 묶는 `pack.py`. 원작 프로그램을 옮기고 자료를 뽑는 도구와 조사 기록은 이 저장소에 넣지 않았다. 그래서 `pe/core.js`의 옮긴 프로그램과 `pe/data.js`는 이 저장소만으로 다시 만들 수 없다.
- `.gitattributes` 릴리스 묶음과 Zenodo 보관본에서 `pe/core.js`와 `pe/data.js`를 뺀다. 저장소와 페이지에는 그대로 있다. 그래서 보관본만으로는 게임이 돌지 않고, 엔진 시험(`qa/engine-tests.cjs`)도 돌지 않는다.
- `qa/` 시험

## 만들기와 시험

```
node build.cjs            # src → index.html, dist/
node qa/core-tests.cjs    # 규약·예제 9묶음
node qa/engine-tests.cjs  # 엔진 16묶음(화면 없이)
```

## 한계

- 제목 화면·암호 입력·끝 장면은 없다. 곧바로 층에서 시작하고, 마지막 방에 들어서면 끝 카드가 나온다.
- 그림자와 거울 속 모습은 원작 주인공 그림 그대로다. 아몰랑으로 바꾸지 않았다.
- 원작 기기의 한 줄 스프라이트 10개 제한을 넣지 않았다. 원작에서 깜박이던 곳이 깜박이지 않는다.
- 자동 실행으로 1층부터 14층 끝까지 이어지는 것을 확인했다(실기기 미확인).
- 그레이스케일과 컬러의 색은 14층의 화면을 캡처해 눈으로 골랐다. 주사선 같은 브라운관 효과는 넣지 않았다.
- 연필은 원작 타일을 새로 그린 것이 아니라 화면을 거른 것이다. 얼굴처럼 작은 부분은 뭉개진다. 움직이는 인물의 윤곽은 자리마다 달리 그어져 일렁인다. 방이 바뀌면 인물 둘레를 먼저 그리고 나머지 배경은 몇 화면에 나누어 그린다. 그레이스케일보다 계산이 많아 느린 기기에서는 끊길 수 있다.
